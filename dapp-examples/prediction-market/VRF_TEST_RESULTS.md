## How Market Resolution Works

### Binary Mode (mode=0)

```
randomness from ESP32 TRNG: [0xe5, 0xf0, 0x3a, 0x32, ...]
                                ↓
                          outcome = 0xe5 & 1
                                ↓
                          outcome = 1 (NO wins)

Probability: exactly 50/50
  Even bytes (0x00, 0x02, ..., 0xFE) → YES (128 values)
  Odd bytes  (0x01, 0x03, ..., 0xFF) → NO  (128 values)
```

### Threshold Mode (mode=1)

```
randomness: [0x50, 0x05, 0x22, 0x5a, 0x6d, 0xac, 0x8e, 0xb5, ...]
                               ↓
              u64 = little-endian(first 8 bytes)
                               ↓
              if u64 > u64::MAX/2 → YES
              else               → NO

Probability: exactly 50/50 (2^63 values each side)
Uses 64 bits of entropy for higher precision than binary mode.
```

## Payout Formula

```
total_pool = yes_pool + no_pool
winning_pool = pool of the winning side
player_payout = total_pool × (player_amount / winning_pool)

Example:
  YES pool = 100 SOL, NO pool = 50 SOL
  Player bet 10 SOL on YES, YES wins:
  payout = 150 × (10/100) = 15 SOL (50% profit)
```
