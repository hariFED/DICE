# DICE Frontend — Premium Dark-Theme Landing + Network Explorer

> **Progress Tracker**: See [PROGRESS section](#progress) at the bottom for live build status.

## Context

DICE is a hardware-backed VRF oracle on Solana with 20 ESP32-S3 nodes. Currently no frontend exists beyond an embedded HTML dashboard in the Rust coordinator. We need a **premium, visually stunning** web app — black + metallic grey + white, WebGL effects, scroll animations, 3D ESP32 model, interactive globe — that serves as both a marketing landing page and a live network explorer. The design quality should match top Web3 infra sites (Wormhole, LayerZero, io.net, Pyth).

## Design DNA

- **Background**: True black `#000000` to `#09090b` (zinc-950)
- **Primary accent**: Electric green `#00FF85` (hardware/matrix aesthetic, Solana green association)
- **Metallic text**: `bg-gradient-to-r from-zinc-200 via-white to-zinc-400 bg-clip-text text-transparent`
- **Typography**: Space Grotesk for body; bold extended font for headlines
- **Cards**: Glassmorphism — `backdrop-blur-xl bg-white/5 border border-white/10`
- **Glow**: `shadow-[0_0_30px_rgba(0,255,133,0.15)]` on interactive elements
- **Texture**: Subtle dot grid or noise overlay on backgrounds

## Tech Stack

### Core (~85KB gzipped)
| Library | Purpose |
|---------|---------|
| Next.js 14 (App Router) | Framework |
| Tailwind CSS + tailwindcss-animate | Styling + animation utilities |

| Lenis | Smooth butter scrolling (5KB, pairs with GSAP) |
| next-themes | Dark mode management |
| @tanstack/react-query | Data fetching with polling |

### 3D Layer (Lazy-loaded, ~255KB code-split)
| Library | Purpose |
|---------|---------|

| @react-three/drei | Helpers: Stars, Float, Sparkles, Environment, useGLTF |
| @react-three/postprocessing | Bloom/glow, chromatic aberration, vignette |
| cobe | Lightweight 5KB globe (used by Vercel) |

### Premium Effects (Copy-paste, zero overhead)
| Library | Purpose |
|---------|---------|
| Aceternity UI | Spotlight cards, aurora backgrounds, meteor effects, 3D card tilt, text generate, tracing beams |

### NOT Including
| Library | Reason |
|---------|--------|
| react-globe.gl | Redundant with R3F; double Three.js load |
| Spline | 300KB runtime bloat, CDN dependency |
| Locomotive Scroll | Lenis is the modern replacement |
| Vanta.js | Redundant with R3F |
| AOS | Framer Motion `whileInView` replaces it |

## Architecture

**Single Next.js 14 app** in `/frontend` of the existing DICE monorepo.

```
frontend/
  app/
    layout.tsx                    # Root: dark theme, Space Grotesk font, Lenis smooth scroll, providers
    page.tsx                      # Landing page (scroll sections)
    explorer/
      layout.tsx                  # Explorer layout (header with nav)
      page.tsx                    # Network overview dashboard
      rounds/
        page.tsx                  # Rounds list
        [id]/page.tsx             # Round detail
      nodes/
        page.tsx                  # Nodes list
  components/
    three/
      Globe.tsx                   # Interactive 3D globe with node points + arcs (lazy, no SSR)
      ESP32Scene.tsx              # Scroll-driven ESP32 showcase: rotate, highlight, explode (lazy, no SSR)
      ESP32Model.tsx              # The actual GLB model loaded via useGLTF (generated by gltfjsx)
      Annotations.tsx             # Floating HTML annotations for ESP32 parts (drei <Html>)
      ParticleField.tsx           # Floating particle background for hero
      EntropyStream.tsx           # Animated entropy visualization (hex data flowing)
    landing/
      Hero.tsx                    # Full-viewport: globe + headline + live stats
      HowItWorks.tsx              # GSAP scroll-pinned 4-step pipeline animation
      ForDevelopers.tsx            # Code snippet with typing animation + comparison table
      ForOperators.tsx             # ESP32 3D model showcase + earnings calculator
      LiveStats.tsx               # Animated number counters (Magic UI NumberTicker)
      TrustedBy.tsx               # Marquee of partner/integration logos
    explorer/
      StatsCards.tsx              # Glassmorphism stat cards with glow
      RoundsTable.tsx             # Live-updating rounds with status pills
      RoundDetail.tsx             # Round timeline + randomness display
      NodesTable.tsx              # Node list with latency/uptime/status
      ActivityChart.tsx           # Recharts: rounds over time
    ui/                          # shadcn/ui components (auto-generated)
    shared/
      Header.tsx                  # Sticky glassmorphism nav, green accent links
      Footer.tsx                  # Minimal dark footer
      GlowCard.tsx               # Reusable glassmorphism card with green glow border
      StatusBadge.tsx             # Round status pills
      CopyButton.tsx             # Copy hex values to clipboard
      AnimatedCounter.tsx         # Number count-up animation
  lib/
    api.ts                       # Coordinator API client
    hooks.ts                     # useNodes(), useRounds(), useStats(), useQueue()
    constants.ts                 # API URL, refresh intervals, brand colors
    types.ts                     # TypeScript types for coordinator JSON responses
    gsap.ts                      # GSAP + ScrollTrigger + Lenis integration setup
    utils.ts                     # cn() helper, formatters
  data/
    nodes.json                   # Hardcoded: [{device_id, city, country, lat, lng}] for 20 nodes
    mock-rounds.json             # Mock round data for development without coordinator
    mock-stats.json              # Mock stats for development
  public/
    models/
      esp32.glb                  # 3D ESP32-S3 model (Draco compressed, <3MB)
    textures/
      earth-dark.jpg             # Night-time Earth texture for globe
    fonts/
      SpaceGrotesk-Variable.woff2
```

### Step 5: 3D ESP32 Scroll-Driven Product Showcase (Apple-style)

GSAP-pinned section (~400vh). Model transforms as scroll progresses:

| Scroll % | Camera/Model State | Annotation |
|-----------|-------------------|------------|
| 0-15% | Fade in, slowly rotating | "Meet the DICE Node" |
| 15-30% | Rotate to USB-C port | "USB-C Power — Plug in, always on." |
| 30-45% | Tilt to LED indicators | "Status LEDs — Green: online. Blue: processing." |
| 45-60% | Zoom to ESP32-S3 chip | "Hardware TRNG + ADC noise. True entropy." |
| 60-75% | Rotate to antenna area | "WiFi Antenna — mTLS secured." |
| 75-100% | **Exploded view** — parts separate | "What's Inside" |

**3D Model Pipeline (NO Blender needed):**
- Option A: Sketchfab GLTF download → gltfjsx
- Option B: AI generation (Meshy.ai / Tripo3D) from photo → GLB
- Option C: Online STEP converter (Aspose/3DViewer.net) → GLTF
- Option D: Procedural geometry in R3F code (fallback)
