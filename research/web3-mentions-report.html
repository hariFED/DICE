Competitive Landscape

Switchboard (SWTCH)

TEE-Based VRF Funding: $11M (Lemniscap, Tribe Capital, RockawayX)

Intel SGX TEE-based randomness (v3). Launched "Surge" with sub-100ms price feeds. First Solana oracle on Jito restaking. Pricing: ~0.002 SOL per VRF request.

DICE Angle: Switchboard relies on Intel SGX (centralized hardware vendor). DICE’s distributed ESP32-S3 nodes offer a fundamentally different trust model — no dependency on Intel’s TEE security assumptions.

ORAO Network

Software-Only VRF Funding: Undisclosed

Multi-node VRF oracle using EDDSA with Byzantine Quorum consensus. Sub-second fulfillment. Pricing: 0.001 SOL (cheaper than DICE).

DICE Angle: ORAO is software-only with no hardware entropy. DICE’s ESP32-S3 hardware RNG provides a fundamentally stronger entropy guarantee than any software-based approach.

MagicBlock (Ephemeral VRF)

Software Plugin VRF Funding: $10.5M (a16z CSX, Lightspeed Faction)

VRF plugin for Solana using Ephemeral Rollups. Primarily gaming infrastructure. Angel investors include Anatoly Yakovenko, Mert Mumtaz, Tristan Yver.

DICE Angle: MagicBlock’s VRF is one plugin within a larger gaming platform. DICE is purpose-built for randomness with dedicated hardware, offering a more specialized and secure solution.

Pyth Entropy

Not on Solana Commit-Reveal

Two-party commit-reveal protocol using hash chains. Currently only available on EVM chains, not yet on Solana mainnet.

DICE Angle: Pyth Entropy uses a similar commit-reveal design but relies on a centralized provider. DICE distributes commit-reveal across hardware nodes — and is actually on Solana.

Chainlink VRF

Not on Solana VRF

The 800-lb gorilla of oracles with VRF across multiple EVM chains. No native Solana VRF. DICE is Solana-native by design.
