# DICE Network — 30-Day Short-Form Video Scripts

## Format
- **Duration:** ≤22 seconds each
- **Visuals:** Non-human, cinematic clips (movies, stock, found footage)
- **Audio:** AI voiceover (ElevenLabs) — scripts included
- **Platforms:** TikTok, Instagram Reels, YouTube Shorts, X/Twitter

## Voice Settings (ElevenLabs)
- **Voice:** "Adam" or "Antoni" (deep, calm, authoritative)
- **Stability:** 0.65
- **Clarity:** 0.80
- **Style:** 0.40
- **Speed:** Slightly slow — dramatic pauses matter

## Music
- Use royalty-free dark cinematic beats (Artlist, Epidemic Sound)
- Bass-heavy, minimal — let the voice lead
- Drop/hit on the final tagline

## Clip Sources
- Pexels, Pixabay (free stock)
- Artgrid, Storyblocks (paid stock)
- Movie clips: fair use for commentary/education — keep under 3 sec per clip
- Screen recordings of Solana Explorer, code editors

## Editing Notes
- Aspect ratio: 9:16 (vertical)
- Quick cuts (1.5-3 sec per clip)
- Text overlay on key phrases (white on dark, same font as branding)
- Subtle zoom/ken-burns on every clip (nothing static)
- End card: DICE logo + "dice.network" for last 2 sec
